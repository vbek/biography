How to tune, and privacy

Tuning. Press Start and allow the microphone. Pluck one string at a time and let it ring. The big letter is the note the tuner hears, and the meter shows how far off it is in cents (a hundredth of a semitone). If the pointer is left of centre the string is flat, so tighten it; if it's right of centre the string is sharp, so loosen it. Turn the key slowly and stop when the meter goes green and the strobe bands stand still. A string gets a checkmark once it has held in tune for half a second.

Tips. Tune up to the note rather than down to it: if you go past, drop below and come back up, so the string holds its pitch. Pluck with your thumb or a soft pick near the neck for a cleaner reading, and mute the other strings. On a phone, hold the mic close to the sound hole or the amp. If a string is a long way off, use Pick string so the tuner doesn't mistake it for a neighbouring string.

Modes. Auto works out which string you're playing. Pick string locks the tuner to the key you tap. Chromatic shows the nearest note for any pitch, which is handy for other instruments. Tap any tuning key to hear a plucked reference note. The reference pitch (A4 = 440 Hz) can be moved for bands or recordings tuned a little higher or lower.

Privacy. The microphone is analysed in this browser tab using the Web Audio API. Nothing is recorded, saved or uploaded, and the page makes no network requests while you tune. Your instrument, tuning and settings are remembered on this device only. Press Stop or close the tab to turn the microphone off.

Keyboard: Space start or stop, 1–6 play a string, A auto, P pick string, C chromatic.
