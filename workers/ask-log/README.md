# ask-log Worker

Stores, in a D1 database, with the visitor's IP and Cloudflare's location guess:
- each question asked in the "Ask About Me" chat (sent by `ask/ask.js`)
- each visit to the home page (`home`), a tool, game or Learn lesson: opened, whether they interacted, seconds in view (sent by `/track.js`).
  Learn shows up as `learn` (the overview) and `learn/ml/<lesson>` (e.g. `learn/ml/knn`), one visit per lesson opened.

## Setup / after changing schema.sql

```sh
cd workers/ask-log
npx wrangler login
npx wrangler d1 execute ask-log --remote --file=schema.sql   # safe to re-run
npx wrangler secret put ADMIN_KEY                            # first time only
npx wrangler deploy
```

Database created before the map's lat/lon columns existed: run this once, **before** deploying the new Worker
(otherwise new rows fail to insert until it's run):

```sh
npx wrangler d1 execute ask-log --remote --file=migrations/001-lat-lon.sql
```

## Viewing

Each view is an analytics dashboard (charts drawn in the browser from the rows, no outside scripts):

- Ask About Me: `https://bibek-koirala.com.np/api/ask-log?key=ADMIN_KEY`
  questions per day (answered vs not), world map, most-asked and unanswered questions, answer topics,
  questions per session, day × hour heatmap, countries / cities / networks, pages, sources, devices, searchable list
- Tool & game visits: `...&view=visits` (add `&app=games/ludo` to open it filtered to one app)
  opens per day (used vs only opened), map, apps, sections, time in view, heatmap, returning visitors, sources, devices, searchable list
- Per app: `...&view=apps`: opens per day by section, sortable table with trend sparklines and change vs the previous period
- `&days=7|30|90|180` picks the range (default 30); numbers compare with the range before it
- Click any country, city, app or list row to filter the whole page; hover anything for exact numbers
- `&format=json` for the newest raw rows, `&limit=1000` for more of them
- Or run SQL in the Cloudflare dashboard: Storage & Databases → D1 → ask-log → Console.

The map outlines (`src/world.js`) are generated by `scripts/build-world.mjs` (see its header).
City dots use Cloudflare's latitude/longitude, stored only for rows logged after the migration;
older rows still count on the country shading.

Location comes from Cloudflare's IP lookup: usually right about the country, rough about the city, and VPN users show up as the VPN.
Entries older than `RETENTION_DAYS` (180) are deleted daily.
